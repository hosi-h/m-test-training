# M-Test 検査トレーニング（PWA）

iPad・iPhone などのブラウザで動き、ホーム画面に追加するとアプリとして使えます。
データは Google スプレッドシートに集約します。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` / `style.css` / `app.js` | アプリ本体 |
| `data.js` | 検査部位・動作・ケア経穴・スポーツ種目／ポジションのマスターデータ（選択肢の追加・修正はここ） |
| `export.js` / `vendor/exceljs.min.js` | Excel書き出し（「履歴」画面。一覧シート＋1人1枚の個人シート。ExcelJS 4.4.0 を同梱しオフラインでも動作） |
| `img/` | 動作イラスト・経穴図（「アプリ_M-Test_トレーニング用_アプリ.pdf」から切り出し） |
| `sw.js` / `manifest.webmanifest` / `icons/` | PWA（オフライン動作・ホーム画面追加）用 |
| `gas/Code.gs` | スプレッドシート連携用 Google Apps Script |

## アプリの流れ

1. 基本データの入力（氏名・年齢・性別・利き腕・利き脚・種目・ポジション・ケガ・既往歴）
2. 検査部位の選択 ⇄ 部位ごとのチェック（「検査終了」で部位ボタンが灰色＝検査済になる）
3. データ一覧（A〜F。検査していない部位の項目は「未検査」と灰色で表示）
   - 修正あり →「再チェック」で 2 に戻る
   - 修正なし → ケア部位（A〜F、複数可）を選択 → ケアする経穴の表示（経穴をチェック、複数可。「その他」は内容を記入）
4. データ保存 → 終了で 1 に戻る

右上の「履歴」から、**この端末に保存したデータ**を開いて修正できます（同じ行を上書きし、修正回数が増えます）。

スプレッドシートは**書き込み専用**です。アプリからスプレッドシートのデータを読み出す機能はありません（URLと合言葉が漏れてもデータは見られません）。そのため、端末から削除した記録や他の端末で入力した記録は、アプリでは修正できません。修正はスプレッドシートで直接行ってください。

## セットアップ

### 1. スプレッドシートと Apps Script

1. Google スプレッドシートを新規作成する
2. 「拡張機能 → Apps Script」を開き、`gas/Code.gs` の内容を貼り付ける
3. 先頭の `TOKEN` を任意の合言葉に変更して保存
4. 「デプロイ → 新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
5. 表示されたウェブアプリ URL（`https://script.google.com/macros/s/…/exec`）を控える

※ コードを変更したときは「デプロイを管理 → 編集 → 新バージョン」で再デプロイしてください。

### 2. アプリの公開（HTTPS が必要）

`mtest-app` フォルダをそのまま静的サイトとして公開します。例：GitHub Pages、Netlify、Cloudflare Pages。
（PWA としてホーム画面に追加するには HTTPS で配信する必要があります）

### 3. 各端末での設定

1. 公開した URL を Safari で開く →「共有 → ホーム画面に追加」
2. 最初に出る「はじめに」画面で入力して「はじめる」を押す（初回だけインターネット接続が必要）
   - 合言葉（手順 1-3 の TOKEN）
   - 入力者名（例：山田 太郎）
   - デバイス名（例：iPad-1）
   - スプレッドシート連携 URL（`app.js` 先頭の `APP_GAS_URL` に URL を入れた場合は表示されません）
3. 合言葉は Apps Script に問い合わせて確認します。正しければ使えるようになり、その端末では次回から聞かれません

### 合言葉について

- 合言葉が通るまで、検査の画面には進めません。合言葉はアプリの中には書かれず、Apps Script 側で確認します
- `TOKEN` を変えると、古い合言葉の端末は送信時に合言葉の入力画面に戻ります（未送信データは消えず、新しい合言葉を入れると送信されます）
- 「設定」の「この端末をロック」で、その端末の合言葉を消して入力画面に戻せます（データは消えません）

## スプレッドシートに保存される内容

- **M-Testデータ** シート（1 人 1 行、修正時は同じ行を上書き）
  - レコードID、作成日時・作成者・作成デバイス、更新日時・更新者・更新デバイス、デバイスID、修正回数
  - 基本データ
  - 検査した部位／検査しない部位、部位ごとの「検査済／未検査」
  - 55 項目のチェック結果：`✓`（チェックあり）／`－`（検査してチェックなし）／`未検査`
  - A〜F のチェック数、ケア部位
  - ケア経穴_A〜F（チェックした経穴）、その他記述_A〜F（「その他」の記入内容）
- **入力ログ** シート：保存のたびに「新規／修正」・入力者・デバイスを 1 行追記

通信できないときは端末内に保存し、オンラインに戻ったとき（またはアプリを開いたとき）に自動で再送信します。

## 元資料との違い（要確認）

- 2.1 頸のイラスト見出し「頸後屈（B）」→ データ一覧に合わせて **頸前屈** としました
- 2.2 膝のイラスト見出し「膝伸展（D）」→ 説明文・データ一覧に合わせて **膝屈曲** としました
- 2.2 腰の「腰側屈（E）」→ データ一覧・入力シートに合わせて **F** に分類しました
- 経穴 E「足の少陰胃経」→ **足の少陰腎経** としました

## 公開リポジトリでの注意（秘密情報を入れない）

このフォルダは GitHub Pages で公開する前提です。

- 合言葉（`TOKEN`）はファイルに書かない。`gas/Code.gs` は `ここに合言葉を設定` のままにし、実際の合言葉は Apps Script の画面でだけ書き換える
- `.gitignore` で、秘密情報になりうるファイル（`.env`、鍵、認証情報の JSON など）と、検査データになりうるファイル（`.xlsx`・`.csv`・`.pdf` など）を除外している
- `.githooks/pre-commit` が、コミットのたびに APIキー・トークン・秘密鍵・合言葉の書き込みを調べ、見つかればコミットを止める
  - 新しくクローンした場合は、最初に一度 `git config core.hooksPath .githooks` を実行して有効にする
- Apps Script の URL（`app.js` の `APP_GAS_URL`）は公開されても問題ない（合言葉がなければ送信できず、読み出し機能もない）
